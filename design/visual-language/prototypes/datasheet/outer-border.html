  1. Hairline: a light line flush outside the existing 1 pt edge. The pill keeps its exact size and look; the outline only adds contrast against the backdrop.
  2. Mat: the same line set 2 pt out, with a sliver of backdrop between. Reads like the hover brackets' drafting language, but is busier.
  3. Bright edge: no new line; the existing edge turns light. Smallest change in code, but it changes the pill's own look rather than adding something outside it.
  4. The setting row above is a mock: Off / Subtle / Bright maps to Off, Hairline at 40%, Hairline at 85%. Default Off, so nothing changes for anyone who doesn't turn it on.
  5. The light appearance (white pill, ink edge) already stands out on dark backgrounds, so the border could apply in dark only. Switch Appearance to Light to judge.
  6. The border applies to every floating surface that uses the pill's frame: the pill, the microphone card and the history card. The small buttons beside the pill would not get it.
